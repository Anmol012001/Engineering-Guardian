# Engineering Guardian — Setup Guide

This guide explains how to set up and use Engineering Guardian in a software
project using Visual Studio Code and GitHub Copilot.

---

## Prerequisites

Before using Engineering Guardian, make sure you have:

- Visual Studio Code
- Git
- GitHub Copilot
- A GitHub account with access to GitHub Copilot
- A Git-based software project

For the demonstration project included in this repository, Node.js and npm
are also required.
