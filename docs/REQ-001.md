# REQ-001 — Active User Retrieval

## Requirement

The system shall provide a way to retrieve only active users.

## Business Rule

A user is considered active when the `active` field is `true`.

## Expected Behaviour

- Active users must be included.
- Inactive users must not be included.
- The original user collection must not be modified.

## Testing Expectations

The implementation should have tests covering:

- Active users
- Inactive users
- Mixed active/inactive users
- Empty user collection
